# Existing Project Workflow

1. Inspect before modifying.
2. Read project instructions and package manifests.
3. Identify architecture and conventions.
4. Locate the smallest affected surface.
5. Preserve existing public behavior.
6. Plan the change.
7. Implement incrementally.
8. Run targeted tests first.
9. Run broader checks after stabilization.
10. Review diff for accidental changes.
11. Update project state.
