# Feature Development Workflow

For a requested feature:

1. Translate the request into acceptance criteria.
2. Find existing related modules/components/services.
3. Identify data, API, permission, UI, and notification impacts.
4. Reuse existing abstractions where appropriate.
5. Implement backend/data contracts first when needed.
6. Implement frontend behavior.
7. Add validation, loading, empty, and error states.
8. Add regression tests.
9. Run targeted and final checks.
10. Summarize changed behavior and verification.
