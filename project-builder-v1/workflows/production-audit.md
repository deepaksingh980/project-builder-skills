# Production Audit Workflow

Audit without making changes unless the user explicitly requests fixes.

Review:

- requirements coverage
- architecture
- code quality
- type safety
- error handling
- authentication
- authorization
- validation
- secret handling
- dependency health
- database indexes/migrations
- API robustness
- performance risks
- logging/observability
- responsive UX
- accessibility
- tests
- build/deployment configuration

Classify findings as:
- Critical
- High
- Medium
- Low

For each finding provide:
- evidence
- impact
- recommended fix
- affected area
